# 本地 Transformer Lab

## 启动

直接在 IDE 中运行项目根目录的 `main.py`。服务就绪后会自动打开默认浏览器；保持程序运行即可学习。可以在 `main.py` 中修改 `PORT`（默认 8765）和 `OPEN_BROWSER`（是否自动打开网页）。

第一次运行如果缺少依赖，在 IDE 选用的 Python 环境中安装：

```powershell
python -m pip install -r webapp\requirements.txt
```

默认页面地址为 `http://127.0.0.1:8765`。端口被占用时直接修改 `main.py` 中的 `PORT`。在 IDE 中停止程序或在终端按 `Ctrl+C` 关闭服务；正常关闭时也会清理它启动的 Python 内核。

推荐使用专门的 Python 虚拟环境，安装依赖和启动服务使用同一个 Python：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r webapp\requirements.txt
```

创建环境后，在 IDE 中选择 `.venv\Scripts\python.exe` 作为解释器，再运行 `main.py`。

如果需要命令行入口，也仍可使用 `python main.py` 或 `python -m webapp --port 8765 --no-browser`。

## 账号与个人进度

首次打开页面会显示登录与注册入口。用户名为 3–32 位，支持中文、字母、数字、下划线、点和短横线；英文大小写视为同一用户名。密码长度为 8–128 位，注册时需要确认密码。

注册成功后直接进入个人空间，再次登录会恢复自己的草稿和进度。右上角显示当前账号，点击“退出登录”会保留进度；同一浏览器的多个标签页共用登录会话，检测到账号切换时页面会重新加载。不同浏览器可以分别登录不同账号。

每个账号分别保存代码段完成记录、草稿、最近运行输出和阶段验收结果，导出的 Notebook 也只包含当前账号的内容。不同账号拥有各自的 Jupyter 内核与工作目录，变量不会相互共享；退出最后一个有效登录会话时，会关闭该账号的内核。

如果升级前已有本机学习记录，首个注册账号可以勾选“将原有本机学习记录和浏览器草稿导入此账号”。只导入一次，原 `progress.sqlite3` 文件会保留；其他账号从空白进度开始。不选择导入时，旧文件也会继续保留。

密码使用随机盐和 scrypt 哈希保存，登录凭据通过 HttpOnly、SameSite Cookie 管理，服务端会话有效期为 7 天；重新启动服务后有效会话仍可继续使用。实现参考 [OWASP 密码存储说明](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) 和 [会话管理说明](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)。

## 学习方式

全部十个阶段已接入，共 81 段示例、35 道独立练习和 30 道验收题，具体目录见 [文件版课程](../course_materials/README.md)。页面顶部始终显示三个学习环节：**示例跟练 → 独立练习 → 阶段验收**，数量按当前章节更新。两个编码环节都需要手敲。未解锁时可点击“独立练习”查看题目目录和解锁条件。当前环节的通过条件显示在讲解下方。

1. 左侧阅读讲解与示例，右侧手敲代码。示例注释可以省略。
2. 点击“运行代码”或按 `Shift+Enter`。Tab 输入四个空格，回车会延续缩进；需要退出代码块时用 Backspace 减少缩进。
3. 示例成功执行且代码结构与左侧一致后，才能进入下一段。核对忽略空白（包括字符串内的空白）、注释、单双引号及字符串中的中英文标点和符号；变量名、数值和文字内容仍需正确。Python 语法需要的缩进和代码符号仍须合法。
4. 独立练习根据测试结果验收，允许不同解法。左侧显示题目和未完成的接口，不提供答案。
5. 完成当前章节的全部示例和练习，再答对 3 道理解题，才算完成这个阶段。第一阶段仍是原来的 13 段示例和 8 道练习，已有进度保持兼容。

例如 `"学习 30 分钟。"` 与 `"学习30分钟!"` 会视为相同，中文逗号 `，` 与英文逗号 `,` 也不会影响通过。归一化只用于核对，运行与保存的仍是自己输入的原代码。字符串文字缺失、变量或数值错误、遗漏语句等仍会给出差异提示；点击提示行号可以定位修改。独立练习继续按照题目的功能测试验收。

代码区采用逐行对照布局：讲解统一放在上方，两侧代码使用相同的字体、行高与起始位置。右侧显示行号，当前编辑行会在左侧同时高亮；纵向滚动任意一侧，另一侧同步跟随。长行不自动折行，可以分别横向滚动，避免一行代码占用多行造成错位。补位空行只影响显示，不会加入你的草稿或执行代码。窄屏下两栏上下排列，仍保留行号与滚动同步。

完成验收后，侧栏自动解锁下一阶段，并提供“进入下一阶段”按钮。再次登录时默认恢复到最早尚未完成的阶段；已完成章节始终可以回看。服务端同时检查章节与代码段门禁，不能通过修改地址、导出链接或直接调用接口跳过前置验收。

第 2–3 阶段主要使用 NumPy，第 4–7、9–10 阶段使用 PyTorch，第 8 阶段另外使用 Transformers。页面会提示缺少的依赖。主要示例都使用小规模数据和 CPU；第 8 阶段 BERT/GPT/T5 从配置随机初始化，不下载权重，也不宣称具备预训练模型的语言能力。第 9 阶段实际训练一个小型字符生成模型，另外可以下载 `optional_pretrained.py`，在联网环境中调用真实的预训练情感分类器。

## Jupyter、保存与恢复

右侧是定制的 Notebook 界面，通过 `jupyter_client` 使用真正的 IPython/Jupyter 内核，不是完整的 JupyterLab iframe。代码在你的电脑运行，可以使用该 Python 环境已安装的包。支持文本输出、表达式结果和错误回溯；本版不渲染富文本或图像输出。

同一阶段顺序学习时，各段共享变量状态。跨阶段执行时会重建内核，每章第一段包含必要的导入和初始化；不会把全部前置章节重新运行。服务重新启动、重置内核或回看旧段落后，只重放当前章节中前面已经通过的代码，恢复本段需要的变量。重放会重复已有代码的副作用，例如小型模型训练与演示检查点写入。普通单段执行超过 20 秒会停止内核，第 8 阶段首次导入模型依赖允许 60 秒；下次运行会恢复当前章节之前通过的代码。

- 账号、密码哈希与会话记录保存在 `.learning_lab/accounts.sqlite3`。
- 各账号的草稿、最近运行输出、通过时的代码和阶段完成状态保存在 `.learning_lab/users/<账号 ID>/progress.sqlite3`。
- 还没写入服务的草稿暂存在当前浏览器，并按账号 ID 区分，重新登录相同账号后会恢复。
- Jupyter 运行文件与代码生成的演示文件也放在各自的 `.learning_lab/users/<账号 ID>/`；原来的教学文件不会被网页覆盖。
- “导出 Notebook”下载当前所选章节已解锁的内容与自己的草稿，可在普通 Jupyter 中打开。导出文件不包含内核运行状态，也不会解锁课程。章节参考资料位于代码区下方。

## 规则边界

输入区拦截快捷键粘贴、菜单粘贴、拖入和替换式自动填充，同时保留中文输入法。阶段与段落门禁由后端依据实际验收结果判断，修改网址或前端按钮不能跳过验收。

这是用于自律的本地学习工具：浏览器无法证明每个字符一定来自物理键盘，拥有开发者工具或本地文件访问权限的人仍可修改程序和进度。它不承担考试防作弊功能。内核具有当前用户的本机文件权限，服务默认只绑定 `127.0.0.1`，请用于运行自己的学习代码。

账号隔离覆盖网页接口、学习记录和内核变量。多个内核仍以同一个操作系统用户运行，拥有相同的本机文件权限，独立工作目录并不是文件系统沙箱。本版适合本机可信用户分别学习，不能直接作为运行不可信用户代码的公网多租户服务。

检查使用临时账号、临时目录和真实 Jupyter 内核，覆盖登录会话、不同账号的进度/草稿/导出/验收隔离、变量隔离、旧记录迁移以及原有学习流程，不会完成或改写你的学习进度。

完整课程端到端检查会实际运行全部 116 段代码并通过十次阶段验收，首次导入 PyTorch/Transformers 时可能较慢。课程内容维护在 `webapp/courses/`，第一阶段继续从原 Notebook 加载；运行 `python tools/build_course_materials.py` 可同步生成文件版教材。
