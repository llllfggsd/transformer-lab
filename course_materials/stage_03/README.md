## 本章内容

- 模型、参数与推理：模型是带参数的计算规则。线性模型 y=xw+b 中，w 和 b 是参数；给定参数计算预测叫推理，通过数据调整参数叫训练。
- 训练、验证与测试划分：训练集更新参数，验证集选择学习率等设置，测试集只做最终评估。时间序列应按时间切分；这里的独立样本使用固定随机种子划分，保证可重复。
- 损失函数：均方误差：回归任务预测连续数值。MSE 对预测误差平方后求平均；损失是一个标量，用于衡量当前参数在一批数据上的表现。
- 优化器：手写 SGD：SGD 是按梯度更新参数的规则。对均方误差，dL/dw=2*mean((pred-y)*x)，dL/db=2*mean(pred-y)。每轮更新后观察损失是否下降。
- 分类、概率与交叉熵：分类预测离散类别，回归预测连续值。二分类可用 Sigmoid 把分数转成正类概率，再使用二元交叉熵。阈值 0.5 是一种决策规则，不是概率本身。
- 欠拟合、过拟合与泛化：容量太小可能欠拟合；高次多项式可能把噪声一起记住。比较训练与独立验证误差，比只看训练误差更可靠。这个小例子只展示机制，单次切分不能证明哪个模型普遍更优。
- 预处理也要避免泄漏：标准化的均值和标准差必须只从训练集计算，再应用于验证和测试集。把验证数据加入统计量会泄漏信息，即使没有使用标签也不合适。

## 阶段验收

1. 哪个数据集用于选择学习率？

- 测试集
- 验证集
- 把全部数据合并

2. 训练误差很低而验证误差很高，通常提示什么？

- 可能过拟合
- 一定已经泛化
- 必须继续降低训练误差

3. 标准化参数应从哪里计算？

- 测试集
- 全部数据
- 仅训练集
