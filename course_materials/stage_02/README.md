## 本章内容

- 向量、矩阵与维度：向量可表示一个样本，矩阵可把多个样本排列成行。矩阵乘法 (B, D) @ (D, H) 得到 (B, H)。这里 B=2、D=3、H=2；请手算左上角，再检查形状。
- 矩阵转置与广播：x.T 交换行列；每行加同一个偏置向量使用广播。keepdims=True 保留汇总轴，(B,1) 才能与 (B,D) 逐行相减。
- 导数、偏导数与数值近似：f(x)=x² 的导数为 2x。有限差分只是近似，用来检查解析推导；h 太大误差明显，太小会有浮点消减误差。偏导表示固定其他变量时的变化率。
- 链式法则：设 z=wx+b、L=z²，链式法则给出 dL/dw=(dL/dz)(dz/dw)=2zx。反向传播就是在计算图上复用这种局部导数。
- 指数、对数与稳定 Softmax：Softmax 把分数变成和为 1 的概率。每个分数先减去最大值可避免 exp 溢出，概率保持不变。axis=-1 表示沿最后一个维度归一化。
- 概率、条件概率与期望：离散分布的概率非负且总和为 1。期望是按概率加权的平均值；条件概率 P(A|B)=P(A∩B)/P(B)，要求 P(B)>0。
- 梯度下降：最小化 L(w)=(w-3)²，梯度为 2(w-3)。每次沿梯度反方向更新。学习率过大会振荡甚至发散；梯度不是新的参数，而是更新方向的依据。

## 阶段验收

1. (4,3) @ (3,7) 的输出形状是什么？

- (4,7)
- (3,3)
- (4,3,7)

2. Softmax 为什么减去每行最大值？

- 改变类别顺序
- 避免指数溢出且保持概率不变
- 使所有概率为零

3. 梯度下降更新参数的方向是什么？

- 梯度方向
- 随机增大参数
- 负梯度方向
