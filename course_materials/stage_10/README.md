# 第 10 阶段：进阶内容

用小规模实验认识现代 Transformer 的位置、归一化、缓存与微调。

共 9 段示例、3 道独立练习和 3 道验收题。

## 使用方式

推荐在网页中逐段学习；也可以打开 `lesson.ipynb` 或运行 `examples.py`。独立练习填写 `exercises.py`，完成后再查看 `answers.py`。

在项目根目录安装本阶段依赖：

```powershell
python -m pip install -r course_materials/stage_10/requirements.txt
python course_materials/stage_10/examples.py
python course_materials/stage_10/exercises.py
```

示例使用 CPU，不依赖 GPU 或下载大模型。第 8 阶段模型从配置随机初始化，只演示架构；第 9 阶段会实际训练一个小模型，文件写在运行时工作目录。网页中的学习记录只由网页的实际验收更新，运行文件版不会自动完成账号进度。

## 本章内容

- RoPE：旋转式位置编码：RoPE 通常作用于 Q/K。这里采用相邻两维成对旋转的约定；旋转保留每对向量的长度，并让点积感受到相对位置。不同实现的维度配对方式可能不同，迁移权重时必须匹配。
- RMSNorm：RMSNorm 按均方根缩放，不像 LayerNorm 那样先减去均值。常见实现再乘可训练的缩放参数。eps 防止分母为零；下面只展示无仿射参数的核心公式。
- SwiGLU 前馈网络：SwiGLU 使用 SiLU(gate(x)) 与 up(x) 逐元素相乘，再由 down 投影回原维度。它的三组投影与普通两层 FFN 不同，比较参数量时需要控制中间维度。
- KV Cache：追加缓存：生成新 Token 时，可缓存历史 K/V，只计算新位置的 Q/K/V。缓存减少重复投影和历史层计算，但新 Query 仍需读取历史 Key。这里只验证单头、无位置编码的核心等价关系。
- 长文本与局部注意力：完整注意力的分数矩阵有 T² 个元素。局部窗口减少允许连接的数量，但下面仍创建稠密矩阵，仅演示可见范围，并不自动实现稀疏加速。FlashAttention 侧重降低存储访问，并没有把所有计算都变成线性复杂度。
- 对称 int8 量化：用 scale=max(abs(weight))/127 将浮点权重映射到 [-127,127]，再反量化近似原值。量化通常减少存储，但精度会有误差；这里是数值演示，不是高性能整数推理内核。
- LoRA：只训练低秩增量：冻结基础 W，只训练 A 与 B，增量为 (alpha/r)BA。B 初始化为零可让初始输出等于原模型。第一次更新时 A 的梯度可能为零，因为此时 B 为零，这不表示实现失败。
- 指令微调：只对回答计损失：指令微调学习按指令输出回答。一个常见做法是将提示部分标签设为 -100，只对回答 Token 计算交叉熵。实际语言模型还要正确处理因果右移与聊天模板；这里的 logits 已与标签位置对齐。
- 偏好对齐：一个 DPO 损失例子：DPO 使用同一提示下的优选/拒绝回答，比较策略与冻结参考模型的回答对数概率差。这里给定已经汇总的回答 log probability，只演示成对损失；完整训练还需要正确掩码、序列求和、参考模型和偏好数据。

## 阶段验收

1. KV Cache 主要保存什么？

- 历史 Key 和 Value
- 训练集标签
- 所有优化器梯度

2. LoRA 通常训练哪些参数？

- 必须更新全部原权重
- 低秩增量参数
- 只改分词器

3. 本例稠密局部 Mask 是否自动带来稀疏计算加速？

- 一定
- 把 True 改成 False 就可以
- 不会，需要合适的实现或内核
